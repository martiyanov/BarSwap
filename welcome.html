Профили закладок

Несколько наборов закладок на панели: на работе — одни, дома — другие, при одной учётной записи Google.

1Выключите синхронизацию закладок Chrome

Панель закладок Chrome — это одна папка, которую браузер синхронизирует между всеми компьютерами с вашим аккаунтом. Пока эта синхронизация включена, Chrome будет перетаскивать содержимое панели между работой и домом и конфликтовать с расширением.

Как выключить: Настройки Chrome (chrome://settings) → «Вы и Google» → «Синхронизация и сервисы Google» → «Управление тем, что вы синхронизируете» → выключите тумблер «Закладки».

Всё остальное (пароли, история, вкладки, расширения…) продолжит синхронизироваться как раньше. Сами профили закладок тоже не пропадут: они хранятся в хранилище расширения и синхронизируются отдельно от обычных закладок.

2Создайте профили

  • Откройте панель расширения (иконка на панели инструментов).
  • Введите название, например «Работа», и нажмите «Создать» — текущая панель закладок сохранится как профиль.
  • Дома создайте профиль «Дом» из домашней панели.

Профили синхронизируются через аккаунт, поэтому список профилей одинаков на всех компьютерах; а вот какой из них активен — запоминается на каждом компьютере отдельно.

3Переключайте

  • Клик по профилю в списке — панель закладок заменяется его содержимым.
  • Текущая панель при этом автоматически сохраняется в «свой» профиль, так что правки не теряются.
  • Первая буква активного профиля видна на бейдже иконки расширения.

Установите расширение на оба компьютера

Расширения, установленные из папки (не из Web Store), Chrome между компьютерами не синхронизирует. Скопируйте папку расширения на второй компьютер (через Google Drive, флешку и т.п.) и там: chrome://extensions → включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите папку.

Как это устроено и ограничения

  • Профили хранятся в chrome.storage.sync — синхронизируются вместе с аккаунтом Google. Лимит — около 100 КБ (несколько тысяч закладок); занятый объём виден внизу панели расширения.
  • Активный профиль хранится локально на каждой машине.
  • Расширение никуда не отправляет данные, кроме синхронизации Chrome; не показывает рекламу и не собирает статистику.
  • Есть «Экспорт»/«Импорт» в JSON — для резервных копий.
